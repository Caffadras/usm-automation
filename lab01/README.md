# Лабораторная работа №1

## Цель

Познакомиться с созданием и выполнением простых Shell-скриптов для
автоматизации рутинных задач в Linux.

## Скрипты

### `backup.sh`

Создаёт архив `tar.gz` с текущей датой и временем в имени. Первый аргумент —
каталог-источник, второй необязательный аргумент — каталог для сохранения
архива. По умолчанию используется `/backup`. Оба каталога должны существовать.

```bash
bash backup.sh /home/user/documents /backup
bash backup.sh /home/user/documents
```

### `cleanup.sh`

Удаляет файлы с указанными расширениями внутри каталога, включая вложенные
каталоги, и выводит количество удалённых файлов. Если расширения не указаны,
удаляются файлы `.tmp`. Расширение можно передать с точкой или без неё.

```bash
bash cleanup.sh /tmp
bash cleanup.sh /var/tmp .tmp .log
bash cleanup.sh /var/tmp tmp log
```

### `disk_usage.sh`

Рассчитывает объём каталога в мегабайтах относительно заданного лимита,
записывает результат в `disk_usage.log` и выводит процент использования.
Третий аргумент задаёт порог в процентах и по умолчанию равен `80`. При
превышении порога уведомление отправляется на адрес из четвёртого аргумента
или переменной `DISK_USAGE_EMAIL`. Для отправки требуется утилита `mail`.

```bash
bash disk_usage.sh /var/log 1024
bash disk_usage.sh /home/user 2048 75
DISK_USAGE_EMAIL=admin@example.com bash disk_usage.sh /data 5000 80
bash disk_usage.sh /data 5000 80 admin@example.com
```

### `ocr.sh`

Извлекает текст из PDF в файл с тем же именем и расширением `.txt`. Для PDF с
уже встроенным текстом используется `pdftotext`; для отсканированных страниц
применяются `pdftoppm` и `tesseract`. Второй аргумент задаёт язык распознавания,
по умолчанию используется `en`.

```bash
bash ocr.sh document.pdf
bash ocr.sh document.pdf ru
```

Перед запуском `ocr.sh` должны быть установлены `pdftotext`, `tesseract`, а
для сканированных PDF также `pdftoppm`. Скрипт проверяет существование входных
файлов и каталогов и сообщает об ошибках в понятном виде.
