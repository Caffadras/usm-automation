# Лабораторная работа №2

## Цель

Научиться работать с Web API из Python-скрипта.

## Запуск сервиса

Сервис курсов валют лежит в `lab02prep`. Нужен Docker.

```bash
cd lab02prep
cp sample.env .env
docker compose up -d
```

Сервис доступен на `http://localhost:8080`. В нём есть данные с `2025-01-01`
по `2025-09-15`.

## Зависимости

Нужен Python 3.7 или новее и библиотека `requests` для HTTP-запросов.
Установка:

```bash
pip install requests
```

## Использование

```bash
python3 currency_exchange_rate.py <FROM> <TO> <YYYY-MM-DD> [--key API_KEY]
```

По умолчанию ключ равен `EXAMPLE_API_KEY`, как в `sample.env`.

```bash
python3 currency_exchange_rate.py USD EUR 2025-01-01
python3 currency_exchange_rate.py eur ron 2025-05-01
python3 currency_exchange_rate.py USD EUR 2025-01-01 --key MY_KEY
```

Результат сохраняется в `data/<FROM>_<TO>_<DATE>.json`. Каталог `data`
создаётся рядом со скриптом, если его нет:

```json
{
  "from": "USD",
  "to": "EUR",
  "rate": 1.0449967801462194,
  "date": "2025-01-01"
}
```

Ошибки выводятся в консоль и дописываются в `error.log` с временем. Скрипт
тогда завершается с кодом `1`.

## Устройство скрипта

- `check_date()` проверяет формат даты и что она попадает в диапазон данных.
  Проверка нужна, потому что сервис для неизвестной даты молча отдаёт
  последний курс, а на неверный формат отвечает не JSON.
- `get_rate()` шлёт запрос: валюты и дата идут в GET, ключ идёт в POST.
  Ошибку соединения, ответ не в JSON и поле `error` в ответе превращает в
  `RuntimeError`.
- `save()` создаёт `data` и пишет туда JSON.
- `main()` разбирает аргументы, вызывает функции выше и при ошибке пишет
  сообщение в консоль и в `error.log`.

## Результаты

Запуск для пяти дат с шагом в два месяца:

```bash
for d in 2025-01-01 2025-03-01 2025-05-01 2025-07-01 2025-09-01; do
  python3 currency_exchange_rate.py USD EUR $d
done
```

| Дата       | USD → EUR (`rate`) |
|------------|--------------------|
| 2025-01-01 | 1.0450             |
| 2025-03-01 | 1.0478             |
| 2025-05-01 | 1.1376             |
| 2025-07-01 | 1.1723             |
| 2025-09-01 | 1.1667             |

Файлы лежат в `data/`.

Проверка ошибок:

| Команда                               | Сообщение                                          |
|---------------------------------------|----------------------------------------------------|
| `XYZ EUR 2025-01-01`                  | `API error: The currency XYZ is unknown`           |
| `USD RUS 2025-01-01`                  | `API error: Unknown currency rus`                  |
| `USD EUR abc`                         | `date must be in YYYY-MM-DD format`                |
| `USD EUR 2020-01-01`                  | `date must be between 2025-01-01 and 2025-09-15`   |
| `USD EUR 2025-01-01 --key wrong`      | `API error: Invalid API key`                       |
| `USD EUR 2025-01-01` (сервис выключен) | `Request failed: ... Connection refused`          |

Эти сообщения есть в `error.log`.

Сервис считает `rate` как `курс TO в MDL / курс FROM в MDL`. Поэтому
`rate` показывает, сколько USD стоит 1 EUR, а не наоборот. `RUS` есть в
списке валют сервиса, но в данных такой валюты нет (там `rub`), поэтому
запрос с `RUS` всегда даёт ошибку.

## Вывод

Скрипт получает курс валют через API, сохраняет его в JSON и обрабатывает
ошибки неверных параметров, ключа и соединения.
